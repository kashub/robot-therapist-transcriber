Robot Therapist Transcriber by Kashub [~]o

Send your AI conversations into Obsidian, locally.

One-click exporter for the open ChatGPT, Gemini, or Claude chat into a Markdown file with YAML frontmatter, ready to drop into your Obsidian vault. The extension auto-detects the provider from the active tab.

How to use

  1. Open a chat at chatgpt.com, gemini.google.com, or claude.ai.
  2. Scroll all the way to the top so every message is loaded into the page (long chats are virtualised).
  3. Click this extension's icon in your Chrome toolbar (the one with the logo above). A .md file downloads.
  4. Move it into your Obsidian vault.

Toolbar badge

OK   success — see DevTools console for filename
ERR   selectors didn't match the page DOM
?    not on a supported provider

Local & auditable

The whole extension is a small folder of plain JavaScript in a directory you control. No third-party servers, no analytics, no auto-updates. After editing the source, reload via chrome://extensions.
